# 下一轮因子研究设计与实施交接

本文承接[研究诊断](FACTOR_MINING_AND_COMBO_RESEARCH_DIAGNOSIS_20260930.md)，用于指导后续实现者。这里提出的是尚未执行的新研究设计，不是已经验证有效的新策略。

## 要解决的问题

下一轮的目标是找出能够形成可交易收益路径的量价结构，并让组合保留其用途和期限。成功不应定义为“增加模型、增加触发次数、完成更多 HTML”，而应体现为：至少一个明确方向或事件通道，在开发样本中具有相对于简单基线足够的预测收益，经过可解释的持有映射仍保留毛优势，并能回答成本是否覆盖、优势在哪些状态存在。

当前值得保留的工程资产很多：唯一 CLI、原生数据时钟、表达式求值、三阶段搜索、来源登记、成熟标签权重、精确账本和已有可视化。无需再建新流水线。新增生产能力仍通过 `python -m src.alpha_mvp.research_cli --config ...` 声明；本次 `docs/diagnostics/` 脚本只是冻结产物审计，不能升级成第二个研究入口。

本轮诊断最重要的约束性事实是：原生 5m 池有弱正信息，小时池移植后的信息较差；最终仓位有显著共同多头偏置；直接逐 bar 使用信号无法覆盖 4 bps；删除 Beta、删除最短持仓等单项操作没有得到跨期一致改善。实现者应围绕这些事实检验假设，而不是预设某个补丁会赚钱。

## 先建立同口径的研究对照

第一批任务应规模有限，不重跑十万表达式。使用现有 18 个接入因子、来源三轨全部 60 个冻结候选的并集，再加入少量明确基线。建议先在可精确复现的 2023、2024 开发片段做链路核对；2025 原始因子复算局部不一致应另行查明，再将其纳入逐因子比较。已冻结 2025 账本可以继续做重放诊断。

每个候选必须能连续追踪以下对象：原表达式值、门控激活状态、标准化后值、条件预期收益、组合贡献、目标仓位、实际仓位及收益。不要只给这七个对象分别一张图；需要用相同时间、相同目标逐层计算信息与 PnL 的变化。先定位是哪里的变换导致了变化，再增加机制。

建议首批只保留以下有辨识力的对照：

| 研究问题 | 固定比较 | 判别方式 |
|---|---|---|
| 前几名截断是否漏掉用途 | 当前 18 与来源 60 的原始候选比较 | 比较不同期限/条件的覆盖，暂不按新复核结果生成赢家名单 |
| 族平均是否损失结构 | 相同标签下原因子 Ridge 与族均值 Ridge | 同样训练行、缩放、正则网格，比较开发验证损失和事件收益 |
| 池子弱还是执行弱 | 因子值、简单条件预测、连续目标、状态机四层 | 在同一目标上比较 IC、条件收益和成本，不混合不同期限指标 |
| 稀疏标准化是否过度饱和 | 当前 IQR 与激活内尺度 | 保存零值、激活率、裁剪率；收益改善需在固定样本外块确认 |
| 小时信号是否被重新放大 | 现有分通道尺度与独立可靠性预算 | 固定尺度单位后让可信度单独控制预算，比较通道贡献 |
| Beta 到底在学什么 | 固定市场暴露、简单趋势、当前两个特征模型 | 将平均持有市场与择时贡献分开，不能只看组合总收益 |

这里的“来源 60”是三个来源各自已有的 20 个，不包含 HHI、共同风险和较早 30k 的方向产品。后两类若加入，应作为另外命名的研究对照，保留原始用途，不能拼入同一方向池后自动平均。

## 把候选从表达式扩展到用途与期限

目前 `expr_hash` 能标识公式，却不能完整标识一个研究假设。建议增加一个轻量研究记录，概念上包含：

```text
表达式与版本
数据可用时钟
激活状态或无条件标记
预测目标与市场投影定义
预测起点与累计期限
发现期方向或发现期条件映射
幅度标定与可信度
计划持仓方式
```

这不是要求每个表达式预先成为完整策略。它允许同一个表达式在不同用途下成为不同候选，避免把预测 5m 反转的分数拿去决定 12h 趋势仓。

第一轮可用少量预定期限，例如 5m、15m、1h、4h、12h、24h；具体网格在开始实验前声明。成本重评集中在前面发现的有限结构，不对全部表达式做重型状态机网格。

对每个期限同时保存两个不同问题：单点延迟收益检验信号何时消失，累计收益检验持有到该时点赚到多少。入场延迟必须单独记录。小时因子的源标签复现，应使用源频率、源 beta 拟合区间和源入场延迟；若改用 5m beta，另命名“移植标签”，不要再称完全保持源标签。

风险候选也保留尺度。未来小时收益的下行平方和与未来 5m 路径的下行平方和分开；原始损失与 `arcsinh` 变换损失分开。只有这样才能判断同一个风险表达式跨目标迁移是否有效。

## 搜索先允许条件性有效 再评价可交易性

可以积极扩大开发样本内的机制探索，不必要求每个候选在每年、每币、每时段都为正。但应把无条件预测和条件预测分成两种评价对象，不能简单把所有门槛降低。

无条件方向候选继续用逐币时间 IC、分位收益差、收益幅度和时间块生存。条件候选另外检查：状态激活率、独立事件数、激活内平均收益/中位收益、尾部损失、1–24h 路径，以及加入状态后对原信号的增量。事件数用于判断是否有可估计的数据量，不能用数以万计的重叠 bar 冒充独立机会。

粗筛最重要的是召回。对全样本 IC、激活内收益、状态交互改善各保留一部分预算；保护字段、机制、期限和活跃率的多样性。中筛才比较时间块和资产广度，细筛才对有限候选做误差、收益、成本和边际贡献。不能要求一个时段专用信号在未激活时段也表现良好，也不能把零输出算作负表现。

门控建议显式保存 `active` 与 `amplitude` 两个对象。未激活输出为零；幅度在激活样本内标定，避免零点质量让 IQR 接近零。缺失数据不等于不激活。若条件本身只负责选择哪个收益模型有效，就作为条件特征保留，不强求它单独具有方向 IC。

最终候选容量也不必急于锁死 20。可先保留约 100–300 个完成用途去冗余的候选，再由低复杂度模型与机制限额控制最终风险；这个数量是下一轮设计建议，不是当前已验证最优参数。去冗余至少同时看激活重叠、收益路径相似和组合边际信息，不能仅凭全部样本上的线性相关。

## 优先研究三种具体量价机制

### 流量与价格反应的条件偏差

用当前已有主动买卖不平衡、成交量/笔数冲击、VWAP 偏离和路径效率，先建立简单的“给定流量和活跃度，价格通常如何反应”的发现期模型。价格偏离该反应的部分，可分别测试补偿与回撤，不预设一定是延续或反转。

最有辨识力的比较是同一流量方向下：低价格反应与高价格反应、低跳跃与高跳跃、持续流量与单次流量。先看累计后续收益是否具有稳定形状，再用模板表达这些结构。当前顶端因子集中于 VWAP/流量短期反转，为这个专题提供了起点，但还不是盈利保证。

### 冲击之后的延续与吸收

区分冲击本身、价格确认、恢复速度三个阶段。高波动、成交激增并不天然看多或看空；其用途取决于冲击方向、路径效率、反向主动流、随后能否恢复。

可用少量事先定义的事件，例如高活跃度下的方向冲击，按过去已完成数据定义状态；检查未来收益在 5m、1h、4h 的形状。若先延续后回撤，单个全期限线性 IC 可能很弱，但仍可能形成两个不同期限的研究产品。禁止用事后最高点、最低点来定义事件时间。

### 时段内异常与市场共同方向

时段专题应研究“相对于同一时段正常状态的异常”，而不仅是时段 flag 乘一个通用表达式。先检查流量、波动和流动性相对时段基准的偏离，以及进入、退出主要时段后的路径。DST 和可用时间沿用现有能力。

共同方向另开明确目标：市场累计收益、趋势持续/反转、上行/下行风险。先让简单的多期限趋势/反转基线体现自己，避免只用下一根 5m 反转模型代表全部 Beta。风险代理可作为这些方向基线的条件输入，也可单独做风险预算；不要强迫同一个表达式同时在残差收益和共同风险上都取得高分。

## 简单模型足够作为第一轮组合工具

先使用直接原始候选的等权、Ridge 和少量显式状态交互，按期限分别训练。族平均、非负冻结方向权重作为对照保留。复杂模型只在简单模型暴露出可验证的非线性不足时加入。

组合输出至少区分预计收益幅度与可靠性。将 0.05 bps 和 5 bps 的预测都缩放到单位标准分，再给相同交易预算，会使下游无法按成本作判断。置信度也不能只由信号自身的分位数推断，应来自过去已成熟标签上的预测校准、误差和条件收益生存。

一个可先研究的简单仓位关系是 `p ∝ conditional_mean_return / conditional_risk`，加入上限及变仓成本门槛；它只是一种基线，具体方差或尾部风险定义需要与期限一致。条件风险升高但收益提升更多时，仓位未必应该机械减半。反之，高标准分但预期收益很小的信号可以保持空仓。

市场共同仓和相对仓分别保留预算、基线和成本，不通过对共同仓单独放大后再混合来决定总风险。资金中性与 beta 中性分别报告。若做 beta 投影，系数仅用过去数据估计，报告投影前后价值；不要把中性化后所有损失都算成“去掉了 alpha”。

研究开发中可以学习状态条件方向，但必须在发现期定义并冻结映射，再用验证期评价，不能看到一个复核期负 IC 后直接把其方向翻转。这与允许积极挖掘并不冲突：探索可以广，解释必须明确。

## 用开发样本找到可交易上限 再评估迁移

若下一轮按用户意图把 2023–2025 用作开发范围，应先检查完整数据是否存在，明确新增开发设计与旧冻结实验的区别。现有报告的年度 Q1 不能冒充全年数据。旧 `holdout_*` 审计列继续隔离，不用于新候选排名。

建议在开发范围内用连续时间块检验，保留“完全样本内拟合的能力上限”和“向后一个时间块外推”两类结果。能力上限只回答字段与表达是否能承载目标，不能当成策略成绩；只有持续地在后续块保留，才说明学到了可迁移结构。各块之间清理跨边界累计标签，滚动特征允许因果 warmup。

2026 若作为新检验期，需要在新设计、候选和执行映射冻结后再使用。重点不是增加防御性流程，而是避免研究反复围绕同一年度损益调整，最后无法判断究竟改进了什么。

首批实验的关键停止条件应是可解释的：

- 如果简单字段和当前候选在任何目标/条件下都没有足够的开发收益幅度，优先改机制表达与标签，不扩执行层。
- 如果候选在预测端有效，进入平滑/门控后消失，先修映射并复核成本，不扩大挖掘数量。
- 如果毛路径稳定、费用仍吞噬，研究更低频的累积/持续状态或不同交易用途，不把费用调小来制造成功。
- 如果只有共同方向赚钱，就把它作为 Beta 产品单独研究；如果只有局部事件有效，就保留局部用途，不要求它全天候承担方向仓。

这些判据允许得到积极成果，也允许及时识别错误方向。下一轮最有价值的交付，是一条能解释“何时、为什么、预测多久、怎么持有”的收益结构，而不是再得到一份名义上覆盖全部机制、实际上仍由弱标准分驱动的组合。

## 实施定位与验证范围

| 需要调整的职责 | 当前代码位置 | 下一轮应保留或补充的边界 |
|---|---|---|
| 目标与增量评价 | `research/purpose.py` | 源目标与移植目标分开；原始及变换损失分开 |
| 快速筛选 | `research/time_series_evaluation.py` | 条件事件的召回，不把所有用途压成统一 IC |
| 模板和候选声明 | `configs/research/templates_*.yaml` | 先固定角色与机制，再枚举参数 |
| 特征形状及预测模型 | `research/factor_combo.py` | 激活内标定、原始候选输入、按期限预测 |
| 在线权重及预算 | `research/factor_combo_dynamic.py` | 形状、收益幅度、可靠性、风险预算分开 |
| 执行 | `research/factor_combo_signal_engine.py` | 依据收益路径选择映射，交易频率只作约束 |
| 报告 | `research/factor_combo_reporting.py` | 逐层同口径信息和 PnL 分解，真实 Alpha/Beta 贡献 |

表内 `research/` 均位于仓库 `src/alpha_mvp/`。实现时仍遵循项目对字段、算子、模板和生产行为变化的元数据、单测、模拟 smoke 及真实数据小样本要求。验证重点应放在标签成熟时间、条件样本、尺度映射和费用会计这些会改变结论的位置，不要用重复的实现细节测试替代研究判据。

本次诊断中，固定执行消融使用日收益标准差 `ddof=0` 计算附带 Sharpe，原生产报告使用的数值略有差别；主要比较统一使用净收益与仓位贡献，未用这列选择变体。下一轮正式报告应统一年化与标准差口径。

优先查明的复算差异记录在[2025 差异表](../outputs/factor_transfer_probe_20260930_v3/reconstruction_mismatch_2025.csv)。目前无法判断原因，不应借此否定已保存账本，也不应把复算数据静默覆盖回原实验。
