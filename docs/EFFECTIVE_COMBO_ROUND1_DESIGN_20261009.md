# 有效组合第一轮：表达能力、币种条件和成熟更新

本轮依据用户新的有效策略验收，复用已有202维数值池，不再生成公式。它检验此前没有充分检验的模型表达能力与条件共享；不是简单继续调Ridge惩罚。

输入OLD106、OLD函数48、混合函数48；加入明确已知的币种身份one-hot。one-hot只是模型设计的控制编码，不是新增市场字段或收益算子。原始市场输入、初始标准化和目标口径沿用源合同。缺失在源处理后为有限值，模型不使用未来价格、时间序号或未来标签作为输入。

目标为直接原始4h价格及资金费代理收益。训练目标以bps数值表示，在±2000bps固定边界截尾；报告评价原始未截尾目标。风险残差先保留旧结果作控制，不将有限任务同时扩成两个标签的模型竞赛。

六个预声明读出：资产条件Ridge（λ10，12月窗，月初更新）；LightGBM7叶静态（120树，叶样本512）；15叶月更新（160树，叶样本256）；31叶月更新（240树，叶样本128）；63叶月更新（240树，叶样本64）；255叶500树、叶样本8的高容量静态诊断。树学习率0.05、L2=10、种子固定。前三种月更新均用过去12月，所有训练标签必须在更新点前完成；每月系数只用于随后一个月。高容量样本内预测单独交付，不能称前向策略。

发现反馈折仍为2024H1、2024H2、2025H1；月初更新在折内部执行，预测以当时成熟标签生成。更新期间可使用已经成熟的前月标签，包含历史验证中的成熟过去标签；不能使用当前或未来目标。源候选全发现期选择偏差仍存在。

执行只作三种有限对照：原RMS固定映射；8bps净边际映射；16bps更保守净边际映射。后两者以预测绝对边际超过预定费用包络后形成目标，用固定50bps预测差作为幅度尺度；目标0.5预算，绝不根据验证缩放杠杆。最终收费按合成实际份额的净变仓，而不是每特征分别收费。币种长短方向由训练模型确定。

模型与执行对照由三个发现折平均日Sharpe减0.25倍折间标准差评分，并报告至少两个正费后折的支持；历史验证不决定本轮组合或参数。另预声明资产条件Ridge＋15叶＋31叶预测的等权组合，检验组合能否抵消单模型误差。全部结果保留。

本轮先建立真实强拟合诊断，再考察历史可用和稳健基线。若只有样本内有效，任务尚未通过，不以过拟合产品冒充稳健基线；下一轮必须针对本轮暴露的预测／条件／执行问题继续。holdout不开放。
