# 假设卡：持续交易中的流动性压力

- **要刻画的机制**：全天交易不代表全天承接能力一致。价格冲击/流动性异常与成交、笔数活跃度和 5m 跳跃交互时，可能预示后续下行或总体波动。
- **输入角色**：A 为 Amihud 或同纽约小时流动性异常；B 为成交额/笔数异常；C 为 5m 跳跃或 5m 对 15m 波动比率。
- **结构**：A 门控、B 短时持续确认、C 风险强度；另测流动性压力相对于活跃度的归一化形式。
- **量纲**：三个角色先逐币标准化；除法分母加正值保护，输出无量纲。
- **目标与尺度**：未来下行半方差及总方差；方向仅由 discovery 推断。
- **边界与失败**：可能只是市场同步波动或极端个别币驱动。需看市场相对目标、币种广度以及事件发生前后的因果时序。
- **生产声明**：`continuous_liquidity_stress` 仅从 YAML 有界生成并进入模板归因。
