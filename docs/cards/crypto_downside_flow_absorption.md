# 假设卡：主动流与价格吸收后的下行风险

- **要刻画的机制**：连续主动卖出流如果伴随 5m 跳跃、交易量集中或路径效率变化，可能反映承接不足与局部去杠杆；即使平均收益方向不稳定，后续下行半方差仍可能上升。
- **输入角色**：A 为 5m 主动流及其早晚变化；B 为 5m 跳跃、成交集中度或价格路径。均为当前完整小时及其历史信息。
- **结构**：A 先经短 EMA 形成持续压力，再用本币历史长窗标准化；与 B 的标准化异常做交互，另测负流门控和流—路径相关变化。不得把正负方向写死为收益 alpha。
- **量纲**：原始角色均为比率/占比；交互前逐资产标准化，输出无量纲。
- **目标与尺度**：优先预测未来 1/4/12 个 1h 决策 bar 的 5m 下行半方差；也可检验总方差。方向由 discovery 推断。
- **边界与失败**：完整小时必须有 12 根 5m bar；在单边持续上涨和大盘共同跳跃中可能只刻画波动 beta。比较绝对与市场相对半方差，并检查币种及纽约时段广度。
- **生产声明**：`templates_crypto_mechanisms_v1.yaml` 中 `downside_flow_absorption`；复杂度和数量上限由 YAML 固定，沿用同一 CLI/归因/holdout 协议。
