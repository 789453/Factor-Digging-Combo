# 基线卡：波动持续性与纽约时钟

- **目的**：检验机制模板是否比最朴素的“当前 5m 波动会持续”和“纽约本地时段本身有季节性”提供额外信息；基线也是有效的风险状态变量，不按纯 alpha 解读。
- **输入**：当前完整小时的 5m 已实现波动、上行波动占比、跳跃占比；或 DST 一致的纽约白天/晚间/夜间 0/1 标记。
- **结构与量纲**：波动值经短 EMA 或本币历史长窗标准化；时钟基线为直接 0/1 状态。波动本身为收益尺度，标准化后无量纲。
- **目标**：未来 5m 上行、下行或总实现方差；分别在绝对目标和市场相对目标上比较。
- **失败方式**：时钟标记和部分风险状态可能几乎对所有币种相同；单独的条件收益不能证明新增模板的交互机制有价值。比较发现/验证方向、币种广度和基线的条件增量。
- **生产声明**：两个有界 YAML 家族 `variance_persistence_baseline` 与 `ny_clock_baseline`，纳入模板归因。
