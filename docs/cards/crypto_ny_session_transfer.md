# 假设卡：纽约交易时段的风险传递

- **要刻画的机制**：加密货币全天连续交易，但流动性和波动可能按纽约本地时刻重复。一个时段的流、波动或流动性异常，只有叠加 5m 局部跳跃/集中度时，才可能传递为后续尾部风险。
- **输入角色**：A 为与此前相同纽约小时比较的流量、区间或流动性异常；B 为当前 5m 跳跃、成交集中或主动流；C 为纽约白天、晚间、夜间互斥时段门控。
- **结构**：A 短 EMA 表示状态持续，B 表示当下确认，C 限定生效时段；所有状态仅使用信号形成时已完整的 bar。
- **量纲**：A/B 为无量纲标准分，C 为 0/1；输出无量纲。C 使用带 DST 的纽约本地时间，不设虚构的加密货币开盘。
- **目标与尺度**：未来上行、下行或总 5m 实现方差。每个时段分别看覆盖和方向，不事后挑选最优时段。
- **边界与失败**：时间门控可能只重现无条件时段季节性。必须与“仅 C”及“仅 A/B”的基线比较，验证条件交互带来的增量。
- **生产声明**：`ny_session_transfer` 为三角色模板，YAML 限定输入和复杂度。
