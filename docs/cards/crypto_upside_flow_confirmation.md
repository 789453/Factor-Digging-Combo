# 假设卡：价格突破与主动流确认

- **要刻画的机制**：24/7 市场没有统一开收盘，短时价格位移单独看可能只是噪声；当 5m/15m 主动买流或同纽约本地时刻的流量异常持续确认时，上行波动或短时收益的条件分布可能改变。
- **输入角色**：A 为价格位移、VWAP 偏离或当前 8h 纽约时段累计收益；B 为主动流、15m 内路径或纽约本地同小时流量异常。
- **结构**：价格与流分别短 EMA，再做长窗逐币标准化；检验相乘、正流门控及相关变化。门控仅是机制表达，方向仍由发现期学习。
- **量纲**：价格收益和流量比率先标准化，输出无量纲；时段按 `America/New_York` 处理夏令时。
- **目标与尺度**：未来上行半方差或收益；两者作为不同实验，不以收益回测替代上行风险预测。
- **边界与失败**：主动流可能伴随反转而非延续；美国白天效应会随制度变化。报告共同市场与相对市场目标，避免把大盘趋势当币种特异 alpha。
- **生产声明**：`upside_flow_confirmation` 的输入、窗口、复杂度由 YAML 限定。
