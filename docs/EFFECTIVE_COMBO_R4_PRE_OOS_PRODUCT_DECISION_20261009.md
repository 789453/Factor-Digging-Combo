# R4新增产品的 OOS 前说明

本说明写于R4历史阶段完成数据评价之后、R4新增状态产品OOS计算之前。R2/R3原始模型的2026结果已经查看；本次属于已见历史的有界因果适配研究，不能称独立盲测。不得按R4 OOS再选窗口或阈值。

保留R1原两条基线、R3在线/静态预测均值edge16：历史验证6.4278%、Sharpe2.5560、回撤3.7709%。后者的原始2026迁移仍弱，不包装为全年度稳健。

对R4此前固定的3月主状态协议，明确观察cal3_edge8这一直接校准产品：历史验证3.3038%、Sharpe2.7537、回撤1.6848%，平均绝对暴露1.2786%，成本盈亏平衡16.7004bps；三个发现反馈折中两个正。cal3_edge16同时保留：1.8559%、2.3383、回撤1.0771%，更低暴露0.5499%。它们按成熟过去gamma乘直接raw-return组合，而不是保持幅度的signed_score。

1/6月校准和方向评分均完整报告，但不据2026选出表现最好的一条。当前不升级EMA/deadband执行：3月方向评分平滑edge16历史验证只有1.5380%、Sharpe1.1030，未显示优于原组合。该事前展示项继续如实保留，不修改配置、冻结推荐或原账本。

下一步评价以上固定产品在R4新增OOS的收益、月份/币种广度、实际持仓与费用；若主要产品不能保持有效性，继续明确的新假设研究，不能以只解释失败结束，也不能擅自事后翻方向。
