# R3：保持有效基线的信号组合与币种权重

本协议在R2新增2026年OOS收益报告读取前冻结；依据仅为R1/R2历史验证及R2发现期预测。R2原池/扩池和OOS冻结材料不改写。唯一生产入口不变，不搜索新公式。

R2发现：扩池96公式后有效性仍在，但全池15叶与等权组合未优于原池；预测误差协方差权重接近等权。因error_i=p_i-y，各误差含有相同的-y。和为1的组合下共同目标方差是常数，而将整个误差协方差向对角收缩会把该共同项变成人工分散惩罚，压住预测间真正较小的差异。因此R3直接在预测矩阵尺度上拟合凸组合，而不把目标共同方差用于正则。

固定四成员：原池15叶、原池Ridge/15/31等权、扩池同容量静态15叶、扩池收缩单币模型。先验权重[0.40,0.35,0.20,0.05]，保留有效共享基线占75%的优先级。过去12月成熟历史预测和标签估计二阶矩E[pp']和E[py]，预测矩阵25%向对角收缩；解非负、和为1的二次目标w'Aw-2b'w，再75%向先验收缩。全局和单币各一套；单币不足500个成熟完整标签时使用先验，充分时单币权重再与同期全局权重各半平均。所有预测是过去按时间产生的输出，不能用拟合期回放替代。

共五套新增产品：(1) 原15叶/扩池静态15叶各半的预测均值；(2) 同两成员先各自edge映射后仓位各半；(3) 原15叶75%+扩池在线15叶25%的预测；(4)上述收缩全局凸组合；(5)上述共享/单币收缩权重凸组合。原15叶和原等权组合两条锚同时复核。注意“预测后阈值”与“成员阈值后平均仓位”因非线性不是同一策略，必须明确区分。仓位组合在净目标仓位变化上只收一次费用，不把成员各自费用简单相加。

所有产品edge8/edge16、幅度50bps、预算0.5、单边4bps、相同12币/4h/5m口径。历史阶段先完成、冻结配置/代码/来源/推荐，再进入OOS阶段；OOS只能核验和报告，不能重选、改权重公式、阈值或币池。2月继续仅为成熟训练桥接，收益窗口2026-03至缓存9月终点。报告收益、日Sharpe、回撤、费用余量、月季/币种贡献、预测IC与R²、权重漂移、自然结束/删失持有和时间块不确定性。

历史预声明展示为pair_position_edge16，因其直接检验“保留各模型的经济边际再低成本净组合”这一问题；展示不自动等于发现推荐或OOS冠军。结果不支持的候选照样保留。
