# R4：成熟历史预测的状态校准（有限研究）

R1/R2正收益只在此前验证期成立，R2新增OOS显示在线模型总体退化。保留失败账本；不得借未来收益翻转信号。本轮问题是：同一冻结组合的预测/收益关系，能否由已成熟的过去预测标签在线识别并校准。此时2026原始模型OOS已经查看，必须称已见历史的因果适配复核，不能称全新独立盲测。选择仍只在发现期/历史验证期，OOS不得挑算法/窗口/币种。

固定输入为R3的pair_prediction（原15叶和扩池静态15叶各半），保留R3全产品及原基线。同一4h/5m账本、12币、4bps、预算0.5、edge8/edge16。

固定过去窗口1/3/6月，月初只使用origin+4h严格早于更新边界的历史预测与标签；只在过去|预测|>16bps的交易相关样本估计gamma=sum(p*y)/sum(p²)，y截断±2000bps，gamma截断[-1,1]，300个成熟完整样本前gamma=1作为明确的基线暖启动。此门槛用于组合校准样本，不用于因子池准入。三个月是事前主状态协议，其余两个窗口完整保留作敏感性比较，不依据OOS选窗。

每个窗口两套产品：calibrated=gamma*p，仍是直接raw-return校准预测；signed_score=sign(gamma)*p，|gamma|<0.05时为零。后者明确为保持原强度的方向评分，不称条件期望收益或费用边际保证。方向变更仅由成熟过去拟合得到，不能根据当月结果翻号。额外仅一套3月signed_score的执行对照：目标仓位EMA6个4h决策，单币目标变化小于0.02时保持上一次目标；数值配置固定。费用在实际净变仓上计算，保留资金费、自然持有及末尾删失。

观察重点：更新gamma的成熟截止、符号/幅度漂移、预测IC与损失、交易活跃度、成本余量、月份/币种集中。若只获得少数持有或接近零暴露，不能以高Sharpe代替有用策略。所有产品保留；报告中将普通预测、校准预测、方向评分和仓位平滑明确分开，不把事后最优窗口冒充事前解法。
