# 固定预测池的训练跨度对照声明

日期：2026-10-09。依据预测整改报告第八节。先完成对已保存六个模型的只读损失分解，再声明本次有限对照；历史验证已经看过，因此这是研究反馈，不是盲测预注册。

只读发现：原始 OLD 挖掘池验证中的动态方差贡献约 +0.02053 个 R² 百分点，而均值项约 −0.09614 个百分点；OLD 坐标和混合池动态项也为负。三个残差模型的误差不主要来自均值偏差。因而需要检验更近期的训练样本是否改善既有组合的系数与均值估计，不能先假定只是交易成本。

唯一实验改变：同一冻结特征池、同一两个直接目标下，比较全部可用历史的扩展训练与起点在每个训练边界前十二个日历月的滚动训练。沿用2024H1、2024H2、2025H1三个折，每个折仅在开始时拟合一次，验证仅在2025-07-01前拟合一次；不在验证内更新。不改变特征、家族配额、抽样时钟、目标、Ridge 标准化、惩罚集合、费用、仓位预算或映射。

复用 `outputs/complex_alpha_prediction_reuse_20261009_v1` 的 OLD/混合各48条冻结函数及106个OLD坐标。源候选仍有全发现期选择偏差；反馈 OOF 不能称独立 OOF。真实数据仍为12币、4h目标与4h抽样，2026-02以后特征与价格不读。

每个协议的惩罚仅按三个发现反馈折平均 MSE 在 [0.1,1,10] 中选。扩展协议应复现既有六模型；滚动协议另有六模型，合计120次有限拟合。历史验证仅报告全部结果，不用于选协议、删模型、翻号或追调窗口。允许结果完全不改善。

解释指标：零预测和训练常数均值基线、平方损失的动态项与均值项、共同/相对分量、月度和逐币诊断、统一固定账本毛费净及实际敞口。历史最优缩幅仅作失效解释，绝不转成可用模型或交易权重。风险投影目标的数值零分量不报告无意义的相关/R²。

交付补全：保留冻结数值特征矩阵、对齐目标、决策日期、币种顺序、公式卡、预测、拟合状态、失败解释及所有账本；避免只交元数据池或空交易清单。不会为本次实验增加大型搜索、树/网络、状态门控或执行优化。

本轮停止判断：若滚动跨度不足以改善迁移，将该假设明确降级；不连续试6月/3月窗口。报告需要区分已解决的准入与可观察性问题、实测未解决的可迁移信息问题，以及尚未验证的条件适用边界。没有盈利承诺，也不把方法整改等同于市场优势已解决。
