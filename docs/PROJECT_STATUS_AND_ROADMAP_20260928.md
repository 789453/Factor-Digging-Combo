## 1. 当前定位

本项目已经从“以 A 股日频截面因子为中心”转为多资产因子研究框架。接下来一段时间的主任务是：

1. 服务加密货币合约；
2. 以逐资产时间序列因子为主；
3. 保留股票与期货的截面接口、字段体系和配置入口，后续继续扩展；
4. 所有资产类别继续共用唯一生产入口、表达式语言、评估协议和证据目录，不另建平行流水线。

12 个加密货币合约构成的小截面不足以支撑大量以 `Rank(...)` 开头的截面表达式。当前加密货币生产配置因此使用 `factor_mode: time_series`，本轮截面表达式占比为 0%。这不是删除截面能力；未来扩大币种池或回到股票、期货研究时，截面模式仍是受支持接口。

## 2. 已冻结的阶段成果

当前认可并保留的实验为：

```text
outputs/crypto_multiscale_sessions_30000_robust20_20260926
```

对应配置：

```text
configs/research/crypto_multiscale_sessions_30000.yaml
```

核心事实：

- 12 个加密货币合约；1h 决策面板，加入 15m 与 5m 的小时内聚合特征；
- 30,000 个生成表达式，29,852 个成功计算；
- 初筛后保留 2,400 个，中筛后进入 650 个完整细筛；
- 34 个满足稳健性资格，最终选择 20 个并形成 10 组低相似度配对；
- 表达式为逐币种时间序列信号，无根部截面 `Rank`；
- 策略为带方向的 signed long-short，不是纯多头；
- 因子方向只由 discovery 数据推断；holdout 不参与生成、筛选、调参或排序；
- 最终 20 个因子在 discovery 与 validation 的净收益和 Sharpe 均为正，且至少两个纽约交易时段的 Sharpe 为正；
- 完成时共有 33 项测试通过。

权威结果解释见 `CRYPTO_MULTISCALE_SESSION_RUN_20260926.md`，跨项目实施公式见 `CRYPTO_FINAL20_FACTOR_IMPLEMENTATION_GUIDE.md`。不得根据 holdout 表现反向改写这次实验结论。

## 3. 当前筛选工作流

当前有效实践是三阶段筛选，而不是对 30,000 个表达式逐一执行全部昂贵统计：

```text
确定性生成候选
  → 初筛：向量化主目标、覆盖率和基础有效性
  → 中筛：按模板/主字段限额保留多样性，检查分段与时段生存
  → 细筛：净 long-short、成本、换手、IC/ICIR、稳健期和完整诊断
  → 多样性选择 20 个
  → 低相似度配对
  → 冻结研究决定
  → holdout 仅审计
```

初筛的职责是快速排除无效表达式，不承担最终质量判断；中筛避免某个模板、字段或窗口提前垄断；细筛才执行成本与稳健性较高的完整策略评估。所有阶段都必须保持确定性、可复现和严格签名缓存。

## 4. 当前结果应如何解读

最终因子不能默认视为“纯 alpha”。它们可能包含：

- 加密货币市场方向或趋势 beta；
- 波动率、流动性、动量、时段或拥挤度暴露；
- 对风险状态的稳定代理；
- 在上述暴露之外的剩余 alpha。

稳定、可解释的 beta 或风格代理不是失败结果。它可以进入 beta/风险溢价策略，也可成为组合的状态变量。未来选择 alpha 时，则应关注控制这些暴露后的剩余收益和边际贡献，而不是把所有预测能力混为一个分数。

当前 20 个因子集中在长窗口相关性动态，尤其是 720h。这既是本轮数据的结果，也是模板与评分偏好的模型风险提示，不应被解释为所有短周期信息无效。

## 5. 已知局限

### 5.1 5m/15m 尚未被原生交易评估

当前流程将 5m、15m 数据向量化聚合成小时内特征，再放入 1h 决策面板。它们参与过搜索，但并不是以 5m 或 15m 的原生调仓频率独立回测。因此最终 20 主要来自 1h 基础字段，不能简单归因为“短周期一定被真实交易费率淘汰”。

下一阶段需要把“特征采样频率、信号更新时间、组合调仓频率、持有期”拆开。5m/15m 信息可用于构造持续数小时的状态，也可进入独立的中频策略通道，而不应与慢信号在单一持有期和单一换手口径下直接竞争。

### 5.2 暴露分解尚未成为标准产物

目前报告展示 IC、收益、Sharpe、分时段表现和结构归因，但尚未系统输出市场、趋势、波动率、流动性、时段等暴露，以及中性化后的剩余表现。

### 5.3 结构化假设仍受基础表达式语法限制

现有模板已支持平滑、差分、相关、门控和跨尺度组合，但仍以有限嵌套表达式枚举为主。事件发生—状态确认—持续性—衰减、流动性冲击后的恢复、非对称波动路径等更完整的经济假设，需要结构化模块和半挖掘机制。

## 6. 下一阶段优先级

### P0：保住研究可信度

- 继续使用唯一 CLI 入口；
- 保持 holdout 防火墙和 discovery 定方向；
- 输出目录不可覆盖；
- 新字段、算子和模板必须有元数据、知识卡、依赖、边界语义与测试；
- 每次行为变化必须通过单元测试、模拟 smoke；数据或指标变化增加有界真实数据检查。

### P1：建立 alpha / beta / 风格暴露分层

为每个候选同时报告原始表现和暴露诊断。首批建议基准暴露包括：

- BTC/ETH 或等权市场收益 beta；
- 趋势/动量 beta；
- 波动率水平与波动率方向 beta；
- 流动性、成交活跃度与拥挤度 beta；
- 美国白天、晚间、隔夜等时段 beta；
- 数据具备后再加入 funding、basis、OI 与期限结构暴露。

输出至少分为 `alpha_candidate`、`beta_candidate`、`style_proxy` 和 `unclassified`。分类和中性化参数只能用 discovery/validation 数据确定。beta 类因子可保留并进入独立策略仓；alpha 类选择重点考察中性化后的 IC、净收益、Sharpe 和对现有组合的边际贡献。

### P1：原生多频率与换手敏感评估

新增频率通道，而不是降低真实成本假设来美化短周期结果：

- 分离特征频率、信号刷新频率、调仓频率与持有期；
- 测试 15m、30m、1h、2h、4h、8h、12h、24h 的衰减/持有期曲线；
- 引入平滑、持续性确认、阈值、无交易带、迟滞和事件触发等换手控制；
- 报告换手、成本前后收益、盈亏平衡成本 bps 和容量代理；
- 在多种费率/滑点情景下复核，而不是只看单一 4 bps；
- 快、中、慢信号先在各自通道选优，再做跨通道组合；
- 严格处理重叠远期收益和时间泄漏。

### P2：结构化模板与半挖掘工作流

将候选分为三层：

1. 通用表达式语法：当前可组合算子和字段；
2. 角色约束模板：快变量、慢状态、门控变量、确认变量、尺度变量各司其职；
3. 专家结构模块：不能被浅层嵌套充分表达的完整经济假设。

优先研究的结构包括：

- 快变量经 EMA/WMA、持续性或累计路径转成慢变量；
- 量价确认、价量背离与流量响应；
- 波动水平、方向、偏度、跳跃占比的非对称组合；
- 流动性冲击、吸收效率和恢复速度；
- OI/funding/basis 与价格、成交、波动的条件交互；
- 美国时段状态门控和 DST 一致的时段基准；
- 一阶/二阶变化、相关水平/相关变化、短长尺度差；
- 事件强度 × 市场状态 × 持续性/衰减。

每个结构化模板需有“假设卡”：经济逻辑、输入角色、量纲、预期方向/适用状态、参数边界、成本包络和失败方式。参数仍由有界 YAML 网格确定性生成，并沿用同一解析、评估、筛选和 holdout 协议。

### P2：可视化与研究台账升级

未来标准报告除当前产物外，还应增加：

- 最终因子按 validation 净累计收益展示 1–5、6–15、16–20 三组曲线；
- 前 5 因子的信号分组/分位数组合图；
- 表达式、方向、累计收益、Sharpe、IC/ICIR、换手和盈亏平衡成本；
- 全时段及最差子时段 Sharpe，纽约三时段热力图；
- 字段、算子、模板、窗口和频率归因；
- alpha/beta/style 暴露与中性化前后对比；
- 因子配对曲线、相似度和组合后的边际提升。

展示排序与候选选择是两个概念：选择继续使用不含 holdout 的多目标稳健评分；报告默认可按 validation 净累计收益排序，并并列展示 Sharpe 与稳健性。图表和 CSV 必须来自完全一致的日期、方向、成本、持有期和复利口径。

## 7. 下一次实现的验收条件

下一阶段不是仅增加表达式数量。至少应满足：

1. 在同一 CLI 中提供原生多频率实验配置和清晰失败提示；
2. 快/中/慢通道各自产生可比较的衰减、成本和换手报告；
3. 候选有 alpha/beta/style 暴露诊断，beta 不被误删，alpha 能看中性化剩余；
4. 至少一组结构化/半挖掘模板进入 YAML、归因和测试体系；
5. 三阶段筛选保留模板、字段、窗口、频率多样性；
6. 标准 HTML 同时满足累计收益、分组、时段、归因、暴露和配对要求；
7. holdout 仍只在研究决策冻结后打开。
