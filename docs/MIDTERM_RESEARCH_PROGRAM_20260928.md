## 研究定位与已形成的共识

研究对象是策略需要的信息：方向确认、上/下行风险、共同市场状态、币种相对状态或条件门控。表达式是承载信息的工具，不是需要无限打磨成本和回测敏感性的最终产品。近阶段优先加密货币 5m/15m 信息经 1h 面板形成的中频机制；股票和期货截面接口保留，唯一生产入口和 holdout 防火墙不变。

前两轮聊天形成的关键纠偏：

1. 冻结的 30k 实验说明旧的统一 4h signed-return 目标和成本口径下，快特征较少入选；不能推出快信息无效。
2. 第一轮后续工作偏重执行情景和聚类几何；这不是用户要解决的核心。执行诊断保留为辅助证据，仅在策略候选阶段适度使用。
3. 核心转为**机制表达**：24/7 交易、纽约本地 DST 时段、波动与上下行不对称、主动流/价格确认、流动性吸收、连续市场的事件与持续状态。不能把时段/流量代理直接称为机构交易事实。
4. 预测对象与信息用途相匹配。未来完整 5m 路径的上、下行半方差比仅看有符号收益更适合一部分中频风险状态；绝对目标与市场相对目标分开，后者仍不等于纯 alpha。
5. 两条提案线共用生产协议：角色约束的算子模板可由仅发现/验证的证据温和引导；人给出市场机制时，AI 提取假设卡、设计基线与有界候选，再进入同一 CLI。聚类是第二条线中的一个结构模块，不单独建管道。

## 中期阶段拆分与停点

### 阶段 A：机制是否提供基线之外的信息（已完成首轮）

首轮实证与迁移检查见 [`CRYPTO_PHASE_A_INCREMENTAL_EVIDENCE_20260928.md`](CRYPTO_PHASE_A_INCREMENTAL_EVIDENCE_20260928.md)。负主动流与 5m 成交集中度的门控是当前最值得进入下一阶段的绝对下行风险线索；联合聚类状态没有通过跨年筛选。阶段 B 是下一个完整工作阶段。

1. 固定预测对象：上/下行半方差、绝对/市场相对、1h 决策时钟和入场滞后；目标标签与模板来源写入 manifest。
2. 以当前同侧波动、纽约时钟作为简单基线。只用 discovery 拟合基线与“基线+候选”模型，在 validation 的相同有效行上比较增量；报告币种广度及失败候选，不按最高回测收益讲故事。
3. 把流—跳跃—流动性联合状态做成**一个**冻结发现期中心的候选，输出有语义的“压力状态亲近度/进入状态变化”，不是任意簇编号。新字段需知识卡、依赖、公式版本、极端/缺失测试和 YAML 归因。
4. 在一个新输出目录完成有界真实数据检查、完整单测和模拟 smoke。阶段停点：能回答“机制超越哪个基线、在哪个目标上有效、是共同风险还是相对风险”；不能回答则记录失败前提，不再扩大量化回测网格。

### 阶段 B：中频预测尺度和原生通道

- 先在同一 1h 决策面板比较未来 1/4/12h 上、下行半方差的信息衰减，区分预测窗口和持仓窗口。
- 再显式接入原生 15m，之后视数据质量接入 5m；独立声明特征采样、信号刷新、组合调仓和持有时钟。较快信号可通过持续性、阈值和状态确认变成较慢信息。
- 成本/换手只在进入策略用途的有界候选上检查；不把成本网格作为全部因子的主要研究目标。

### 阶段 C：人机半结构化机制研究

- 人提出“要赚/避免哪类市场行为、可观察迹象、策略用途及失效条件”；AI 形成假设卡、数据依赖、对照基线、候选模块、检验结果和下一步修订。
- 首批专题限于流动性冲击后的吸收与恢复、纽约时段风险传递、上下行波动路径、流—跳跃—流动性联合状态。OI/funding/basis 仅在源数据完备后加入。
- 仅在独立时间段上确认超越基线的模块才进入正式策略研究。稳定 beta/风险代理可以保留，但名称与用途必须准确。

## 不变约束

所有行为改变通过单测与模拟 smoke；数据/指标改变做有界真实数据检查。所有完成输出不可覆盖。方向和模型拟合仅 discovery；validation 测生存与增量；holdout 仅在研究决定冻结后审计。低成本的粗/中筛保护模板、字段、窗口和频率多样性，昂贵统计留在少数幸存者。
