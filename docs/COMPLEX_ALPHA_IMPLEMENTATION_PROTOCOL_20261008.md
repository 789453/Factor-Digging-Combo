# 复杂表示研究实施冻结稿（2026-10-08）

本实施承接 `COMPLEX_ALPHA_REPRESENTATION_AND_MINING_DESIGN_20261008.md`。新增模块属于已有 aligned_crypto 研究模式，不增加生产 CLI。研究输出全部使用新目录。

## V1：表示、预测与可交易价值的三级检验

观测为已完成 1m 的价格创新、相对共同价格创新、有向**计价**成交比例、log 成交额、log 笔数、平均计价成交尺度、区间、收盘位置及成交均价偏离。逐点位置/尺度只使用之前七天（最少一天）；真实零与缺失分开；金额和笔数取 log1p 后标准化，价格采用过去 RMS。记录截尾比例。所有结构每 15m 完成时可用；首根承担收益的是之后的完整 5m bar。

F1 为固定对数分组的 ilr、条件指数倾斜奇偶坐标及倾斜有效样本；F2 为单侧 Haar 细节、包络和滞后跨尺度耦合；F3 为四通道分段线性路径的独立 Lyndon 对数签名，最高三阶，120/240/720 分钟；F4 为六状态循环/转移及占据对照；F5 为四通道短长收缩 SPD 相对矩阵对数；F6 为有限记忆核和有界二三阶响应；F7 为一个冻结种子的分布 Fourier 核坐标。F8 独立研究状态创新，不混入首轮主候选竞赛。

因算力和分钟内数据边界，先实现自然分钟时钟主库，活动时钟为独立消融，不假造分钟内逐笔。普通签名与对数签名严格区分；所有坐标携带原料、支持长度、阶数、是否拟合和数值规则。

初始 2023H1 校准，2023H2/2024H1/2024H2/2025H1 四个扩展训练外推折。标签完整结束后才可训练；边界按真实目标期限清除。滚动过去 beta 构造风险残差，折内旧表示基线构造预测残差。2025-07—2026-01 为已见历史验证，2026-02—2026-09 为已见历史测试。holdout 仅在所有候选、组合、尺度、执行决定冻结后审计。本轮研究者不使用审计结果修改结构。

固定复杂候选预算 F1/F2/F3 各 6000、F4/F5/F6/F7 各 2250、旧表示 3000，总 30000；另给旧表示 30000 同预算对照。候选为类型化稀疏投影/有限交互，不用重复窗口凑数。每定义两个目标，实际定义、评估、拟合与反馈次数分别报告。初筛采用轮换相位 4h 起点，600 中筛、60 精筛。联合结构读出单独有预算，避免逐坐标 IC 先行清空。固定随机种子和支持基，保留全部候选身份及失败原因。

## V2：有界拟合与集合增量

结构块 ridge、有界旧表示非线性读出、联合低秩交互使用相同折和目标。旧非线性提供192个固定交互，联合读出提供128个固定投影；它们是容量对照，不是所有架构严格同参数数或同有效自由度。拟合、标准化、基线残差化均折内进行。只用发现期外推选择惩罚和结构。Optuna 有界 TPE 持久化，在有限结构块上搜索，累计所有试验。候选筛选优先预测损失增量、方向/跨折广度、集合贡献；固定执行的费后效用在幸存者上测量。

## V3：证伪、冻结与归档

精筛候选检验顺序破坏、跨通道错位、一/二/三阶、仅能量/有向耦合、对角/完整几何、状态占据/转移、主效应/交互。替代数据仅检验其保留条件下的结构必要性。整组币种按连续时间块联合 bootstrap；报告非重叠起点敏感性、随机标签错位的搜索赢家以及风险定义敏感性。

执行映射统一：预测强度由发现 OOF 分布定尺度，15m 更新、固定 EMA/无交易带/现金与动态市场 beta 约束；不得为各候选独立搜持有期。5m 简单收益自融资篮子账本，资金费结算付给此前持仓，费用按实际变仓。另保留对数收益研究口径供历史对照；不将两种财富约定混用。成本 4bps/单位变仓，另列 0/2/6/8bps敏感性。数量不能替代效果，失败/风险/信息但不可交易分别归档。

验收：独立单元/参考测试、模拟 CLI smoke、有界真实检查、全规模结果、不可覆盖/签名/冻结、报告与账本对账、独立 HTML。不承诺市场必然提供高 Alpha；以折外增量和扣费证据决定产品等级。

## V4：最终实际合同与结论强度

上述V1—V3保留设计演进。最终R4使用2023Q1初始化，2023Q2首次校准，其后四个折评估；标签是固定份额的简单价格收益减实际价格加权资金费，再经过当时已知现金/共同beta加载的对称投影。过去创新采用同一投影估风险；预测恢复该风险尺度后，与执行的共同加载约束相容。原log/LOO版本只作为R1—R3历史研究，不将其增量数字与R4视为严格同权对照。

最终新增高斯矩匹配分布参照与OLD训练残差导向的rank2交互，52格同惩罚比较+20次TPE。变更后的完整链路和只读复核有139项单元/参考测试和独立v16模拟CLI；最新完整检查为outputs/complex_alpha_20261008_final_tests_v9.log，139通过、1项既有预热空切片警告。实数研究使用新的round4目录、源快照和配置签名。明确关闭信号失活旧仓，不通过验证优化退出阈值。

当前实施的替代数据实验只证明表示辨识，不直接证明训练预测函数的结构必要性；错位零假设只重新评分最多40个幸存者，不重新搜索六万定义。消融、块bootstrap和非重叠起点提供条件证据，不能包装为严格嵌套搜索后显著性。固定倍率、完整额外风格风险模型、每种结构的预测层替代数据重训与新未见期均不属于已经完成的结论。若这些证据不足，降低产品等级，而不以实现规模推断成功。

F7的最终参照是同窗均值/协方差匹配的高斯特征函数偏离，回答高阶分布是否超过普通矩。它没有实现设计第6节提出的历史趋势/波动/活动/时段近邻条件参考分布；两者不能混称。设计第8节的结构变异目前是冻结有限语法与确定性种子展开，没有自适应树进化；Optuna作用于读出架构/惩罚。第9节本轮主实验检验残差方向目标，未另训练并证明Beta择时和风险预测产品。这些是明确的实施范围，不以负Alpha结果替代它们的独立验收。
